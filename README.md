# 📚 RAG University Notes Q&A App

An AI-powered app that answers questions directly from
your study material and PDF documents using RAG technology.

## 🔗 Live Demo
https://rag-notes-app-26ujreqjmbrclwpkdsdeun.streamlit.app/

## 🤖 How It Works
1. Upload any PDF document
2. AI reads and understands the content
3. Ask any question in plain English
4. Get accurate answers instantly

## 🛠️ Tools Used
- Python
- LangChain
- Groq API (LLaMA 3.3)
- FAISS Vector Database
- HuggingFace Embeddings
- Streamlit

## ⚙️ Features
- PDF document loading
- Text chunking and embedding
- Semantic search using FAISS
- LLM-powered answer generation
- Clean and simple UI
